# Public screenshot assets

These are real Media Center screenshots from isolated sample collections and controlled test servers. No personal library data or credentials are included. Media is not bundled with the application.

- `music.png`, `audiobooks.png`, `podcasts.png`: the explicitly labeled sample collection in Media Center 1.0.0. Covers are original code-generated designs.
- `home.png`, `local-library.png`, `recap.png`, `settings-search.png`: 1.0.0 desktop integration checks using fixture servers, generated silent audio and disposable profiles. Statistics reflect only the test session.
- `immersive-player.png`, `lyrics-appearance.png`: 0.7.6 controlled playback checks with original test lyrics; these views and appearance controls remain available in 1.0.
- `customization.png`: the 0.7.0 color/font editor retained in 1.0.
- `recap-styles.png`: the actual 1.0 Recap renderer with explicitly illustrative statistics. Generated by `scripts/recap-gallery.cjs`; no sample statistics enter the real app database.
- `social-preview.png`: a 1280 x 640 composition generated by `scripts/render-release-art.cjs` from the reviewed `music.png` screenshot and project branding. Shared by README and website Open Graph metadata. Upload in GitHub repository Settings > General > Social preview.
- `icon.svg`: the app mark from `build/icon.svg`.

All assets are part of this GPL-3.0-only project. To refresh, run desktop checks with MPV_TEST_PATH, review images in ignored artifacts/, and copy only selected screenshots here. Never publish profiles, logs, private addresses or personal collections.
