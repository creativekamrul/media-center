# Screenshot provenance

All images are unedited Windows screenshots captured by this repository's desktop validation scripts. No personal library data, credentials or third-party cover images are included. Media is not bundled.

- `home.png`, `local-library.png`, `immersive-player.png`, and `lyrics-appearance.png`: Media Center 0.7.6 with isolated test servers, generated audio fixtures, original test lyrics and local test playlists. Home statistics reflect that test session, not a user's activity.
- `music.png`, `audiobooks.png`, `podcasts.png`, and `customization.png`: Media Center 0.7.0. The library views use the app's explicitly labeled sample collection; customization shows real Settings during a test session. These older screenshots illustrate features retained in the current release.
- `icon.svg`: the app mark from `build/icon.svg`.

All assets are part of this GPL-3.0-only project. To refresh, run the desktop checks with MPV_TEST_PATH, review the images in ignored artifacts/, and copy only selected screenshots here. Never publish profiles, logs, private server addresses or personal collections.
